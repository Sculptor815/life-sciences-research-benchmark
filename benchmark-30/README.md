# Open 30-question benchmark

This directory contains the exact evaluated questions and versioned reference materials. All text is English. The original 30 questions and first-version references were carefully reviewed by the project owner. Second-version revisions are Codex-authored updates made at the owner's request; they must not be described as already human reviewed.

Version-one reference prose is preserved. All 30 version-two references are revised and frozen. Each has at least 703 words. Personal second-round grading is in progress; partial work is not a complete evaluation. New scores reuse saved answers; there are no new candidate or judge API calls. The rubric and reference revisions are post-hoc. Once released, this set is an open benchmark, not a secret held-out set; future uses must account for exposure and possible memorization.

Synthetic disputed-source dossiers concern fictional records, not misconduct allegations against real people.
