# inf-r01: revised reference

Version: reference-v2.1. All procedures and numerical pilot criteria are proposed, not claims of historical execution. New revisions await owner review. Scientifically equivalent alternative designs can satisfy the rubric.

The biological question is which genes undergo substantial expression changes between defined biological conditions, especially when only a few independent specimens are available. The methodological question is whether information sharing can reduce unstable estimates without erasing real large effects. These questions are connected but not identical: a numerically stable estimate is useful only if it supports a more reliable biological comparison. The proposal should therefore evaluate effect accuracy, uncertainty, and interpretation rather than declaring success because a plot looks smoother or contains more significant genes.

The hypothesis is that a shrinkage model with suitably adaptive tail behavior can accommodate both many modest effects and a small set of genuine large changes. A competing explanation is that apparent large changes mostly reflect low counts, uncontrolled batches, sample swaps, or a poorly fitted likelihood. Another is that changing the prior simply preserves more noisy extremes. The proposed method must retain strong effects when supported by information while still moderating weakly identified effects. Its benefit cannot be judged only on a favorable set of genes selected after inspecting the results.

Stage one defines the biological contrast. Specify the organism, tissue or cell population, conditions, independent biological unit, and intended effect scale. Record whether the contrast concerns treatment, genotype, time, or an observational association. Define covariates and interactions that are justified by the experimental design. If condition and batch are perfectly confounded, no shrinkage method can identify their separate effects. Such a dataset should fail eligibility for a causal contrast rather than be rescued by an attractive statistical procedure. State that observational expression differences do not automatically identify causal gene functions.

Stage two screens candidate datasets before analysis. Require accessible raw data, a complete sample map, adequate biological replication, interpretable experimental design, and evidence that the selected figure or conclusion is actually supported by the available measurements. Inspect correction or retraction status and unresolved data-quality concerns without equating criticism with fabrication. A highly cited methods article is not sufficient assurance. For a historical forecasting task, only data and methods available at the cutoff may enter the candidate packet. Later datasets may be used privately for validation, with that temporal distinction explicitly labeled.

Stage three freezes a raw-input manifest. Record accession identifiers, filenames, sizes, checksums, sample identities, library type, strandedness, read pairing, and reference versions. Document acquisition failures and mismatches. Confirm that technical sequencing runs from one specimen are not mistaken for independent biological replicates. Preserve an immutable sample sheet and store a separate analysis design table. Every count column must map unambiguously back to its originating raw files. This bookkeeping is scientifically important because a sample swap or duplicated run can create persuasive but incorrect biological differences.

Stage four implements preprocessing in an isolated, versioned environment. Record each tool version, reference genome and annotation checksum, command arguments, random seeds where relevant, and resource limits. Evaluate read quality, contamination indicators, mapping behavior, library composition, and sample-level anomalies using prespecified criteria. If trimming, alignment, quantification, or filtering is changed after examining the primary result, record the change and label the resulting analysis exploratory. Preserve intermediate quality reports and the final count matrix. Failure to complete preprocessing is an execution result, not an invitation to substitute an unrelated processed matrix silently.

Stage five constructs a matched baseline analysis. Use one sample set, one design matrix, one gene annotation, and one defensible count likelihood across estimator comparisons unless a deliberate difference is part of the hypothesis. Confirm the contrast direction and units of effect estimates. Check design-matrix rank and dispersion behavior. Document how size factors or other offsets are estimated and which assumptions they impose about composition. Genes with inadequate information should have their uncertainty represented honestly. Removing them from one method only would bias the comparison.

Stage six defines the proposed estimator independently of the target answer. A plausible route is to replace a thin-tailed effect prior with a heavy-tailed form whose scale adapts to the observed information across genes. Specify which coefficients are regularized and which, such as intercepts, require separate treatment. Describe the likelihood, prior, optimization or approximation procedure, convergence checks, and returned uncertainty summaries. Set parameters using a training or development procedure that cannot inspect the confirmatory test labels. Merely naming a software package is not a method proposal.

Stage seven uses simulations with known effects to make the tradeoff measurable. Vary count abundance, dispersion, sample number, library composition, proportion of changed genes, effect-size distribution, and covariate imbalance over a prespecified grid. Include scenarios that violate the proposed prior's assumptions as well as scenarios favorable to it. Generate independent simulation replicates and retain the seeds. Evaluate absolute error, signed bias, rank recovery, sign errors, and uncertainty calibration across both information and true-effect strata. A single aggregate error can conceal severe failure on rare but biologically important changes.

Stage eight obtains an independent reference for real-data evaluation. A large-replicate experiment can provide a more precise comparison than a small subset, but it is not literal ground truth. Separate the samples used for the small-sample estimate from those supporting the reference whenever possible. If the same observations contribute to both, quantify and disclose the dependence rather than interpreting agreement as independent validation. An orthogonal expression assay or independently collected cohort can strengthen the biological check, with its own measurement limitations and gene-selection rules stated in advance.

Stage nine compares methods under equal conditions. Freeze the gene universe, treatment of zero counts, covariates, scaling convention, and target effect definition. Report performance for all eligible genes and prespecified subsets rather than only the strongest favorable examples. Separate estimation of effect size from hypothesis testing, because a well-ranked list does not prove false-discovery control. Likewise, a low estimated false-sign probability is meaningful only if calibrated in the tested regime. Include runtime, convergence failures, and numerical exceptions instead of dropping difficult cases from the reported denominator.

Stage ten designs figures to test claims rather than imitate appearances. Produce matched estimated-versus-reference effect plots, error-versus-information plots, rank-recovery curves, uncertainty-calibration displays, and sample-quality summaries from stored numerical tables. Fix axis definitions, transformations, limits, and aggregation rules. Retain both the plotted table and the rendering code so that graphical agreement can be traced to underlying values. If reproducing a published figure later, compare numerical quantities and stated conclusions with predefined tolerances; matching colors or panel layout is not evidence of biological reproduction.

Stage eleven examines robustness. Repeat the analysis under justified alternative annotations or preprocessing choices, leaving the primary analysis frozen. Investigate whether a small number of samples, a specific batch, or an extreme count drives the claimed advantage. Use appropriate resampling at the biological-sample level, not independent resampling of correlated technical runs. Assess whether the proposed estimator retains large effects because they are consistently supported across samples or because its prior fails to constrain outliers. Distinguish sensitivity analysis from post hoc tuning to reproduce a preferred result.

The decision rule requires simultaneous improvement in the intended error tradeoff and acceptable uncertainty behavior. Preserving a large estimate is beneficial only when independent information supports its magnitude or direction. A method that improves a few true large effects while greatly increasing false extremes may fail the stated objective. A result confined to simulations generated from its own prior is inadequate evidence of general usefulness. An informative null finding can show that a more flexible prior offers little advantage in a particular information regime; that result still advances the methodological question.

Finally, report a bounded biological interpretation. Improved estimation can help prioritize genes for follow-up, but it does not establish molecular causality, pathway activation from transcript counts alone, or universal superiority across datasets. Distinguish the proposed future research direction from a completed raw-data reproduction: this draft has not downloaded a qualifying dataset, run an end-to-end pipeline, or regenerated an author's figure. Those require an independently audited dataset-and-figure package. For historical matching, the meaningful achievement is the complete argument connecting noisy effects, a justified change in regularization, independent evaluation, and calibrated biological interpretation, not recollection of the later method's name.

## Strict second-round operational extension

Operational contract for this proposed protocol. Before collecting confirmatory data, consult the relevant primary Methods, supplements and validated assay/tool protocol. Build a transfer table containing each reagent or tool, source/version, source condition, proposed local condition, reason for changing it and pilot result. This is a required future action, not a claim that unavailable historical procedures have been recovered. Unknown identities or settings remain unresolved prerequisites until the table is complete. Do not replace absent sources with invented precision.

Define positive, negative and procedural controls before treatment: specify which comparison establishes technical responsiveness, which estimates background, and which separates the manipulation from its delivery or handling. Name the competing explanation each controls. A positive control's pass threshold is fixed on independent calibration, not on whether the main treatment gives the hoped-for effect. Use the assay-specific controls below; do not demand unrelated PCR, viral or imaging procedures. If genetic material is amplified, record template/amplicon length, validated primers, reagent amounts, polymerase-specific extension logic and sequence identity. If viral delivery is essential, record the actual construct, functional titer, delivered amount, target-cell number or tissue volume, expression interval, distribution and toxicity; vector-genome concentration alone is not a functional infection dose. These details become obligations only for the chosen route.

Use a separate development pilot to estimate nuisance variability and operating ranges. A proposed minimum of three independent preparations is a variance-discovery starting point, not an automatically adequate powered experiment. Choose a smallest meaningful effect and then simulate or calculate the number of independently allocated units required for a stated interval-width or power target, propagating uncertainty in pilot variance. Fix the maximum sample size, intermediate technical checks and stopping rule before confirmation. If resources are insufficient, report the detectable effect and uncertainty instead of counting subsamples as new replication. Randomize independent units within justified day/batch blocks, balance processing order, conceal allocation where possible and keep outcome scoring and data processing blinded. If an element cannot be blinded, document why and substitute automated locked processing or an independent coded assessment.

Keep a registered primary contrast and multiplicity family. Prespecify how censoring, weak signal, missing units and technical losses are handled. Retain raw and normalized measurements, original assigned-unit denominators and every nonresponse. A failed instrument or sample-identity check can invalidate a measurement under a prospective rule; a biologically negative result cannot. Analyze independent-unit summaries or a justified nested model, verify its assumptions and report effect sizes with intervals. Use equivalence bounds only when an adequately precise absence claim is intended. A non-significant comparison is otherwise inconclusive.

Troubleshoot in the order identity and delivery, reference/control performance, measurement dynamic range, then the biological hypothesis. Record each change, its reason and all failed runs. Change only the implicated variable in a bounded pilot or an explicitly designed factorial pilot; freeze the revised procedure and obtain fresh independent confirmation. Do not retune on the confirmatory outcome. Alternative mechanisms and outright failure of the hypothesis are valid results. The audit trail links sample/unit IDs to raw files, calibration records, timestamps, deviations, exact analysis versions, settings and outputs. A second analyst should be able to reconstruct the reported contrast from those records. No part of this reference claims an experiment has already succeeded.

Case-specific implementation.

Before computation, identify eligible raw-count/RNA-seq datasets and inspect their primary Methods, sample allocation, correction status and data/code availability. Resolve actual accessions, checksum manifests, reference releases, sample pairing and intended panels; placeholders cannot count as reproduced data. Separate discovery, tuning and independent validation samples, and define the biological condition contrast and independent allocation unit.

Use the same identifiable NB count likelihood for baseline and proposed methods: Var(Y)=mu+alpha*mu^2, with library offsets and explicit design covariates. For the effect coefficient, compare a Normal prior to a heavy-tailed alternative such as a centered Cauchy density proportional to 1/[1+(beta/s)^2], with its scale learned only under the stated development procedure. Separate intercept/nuisance handling, effect estimation, significance testing and false-sign estimation. State optimizer/convergence diagnostics and report failed genes rather than silently dropping them.

A proposed simulation grid includes independent n=3, 6 and 12 per group, multiple abundance/dispersion strata and both light- and heavy-tailed or mixture true effects. These are evaluation scenarios, not actual dataset dimensions. Include batch imbalance, outliers, null genes and large well-supported effects; generate independent replicates until Monte Carlo interval precision is adequate. Compare error, bias, ranking and sign/interval calibration across true-effect and information strata under matched filtering. A prior can preserve noisy extremes as well as real effects, so success requires both reduced low-information error and preservation of independently supported large effects.

For empirical validation, use disjoint larger-sample reference estimates with uncertainty or independent orthogonal expression measurements; a high-n estimate is not infallible truth. Lock methods before holdout evaluation and retain failed/convergence cases in denominators. Export numerical estimation/error/calibration tables behind figures, immutable seeds, environment, commands and resource logs. Rerun from raw inputs where available, compare numeric tolerances and audit source differences. A claimed exact paper reproduction is blocked until raw inputs and target figures are identified. The historical target is the adaptive heavy-tail tradeoff, not simply trying another differential-expression package or preserving every large estimate.
