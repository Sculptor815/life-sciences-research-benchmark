# inf-d03: first-round reference

This is the unchanged first-round reference text. The owner confirmed careful review on 3 October 2026. Earlier pending-review statements inside the historical text are retained as part of the snapshot, not current metadata. Corrections and expanded execution requirements appear in version two.

All experiments and analyses below are proposed; no historical data are reanalysed. The design addresses a study in which treatment is assigned to donors or animals but many cells or fields are measured per donor. The central rule is that the randomized treatment level defines the experimental unit, so cells cannot be treated as independent treatment replicates for a donor-level treatment claim.

Preparation and QC. Before analysis, reconstruct the allocation and splitting history: which donor or animal received which treatment, how many independent donors per arm, how many cells, fields or libraries came from each donor, and whether position or time was aligned with treatment. Build a sample sheet with unique identifiers for donor, cell or field, treatment, batch, position, time and any processing variable. QC should verify that identifiers are unique, that treatment is assigned at the donor level, and that the number of independent units per arm is known. If the allocation history cannot be recovered, the donor-level effect cannot be identified merely by adding a donor random effect to a cell-level model.

Experimental unit, allocation and blinding. The inferential unit for treatment is the donor or animal. Cells, fields and technical measurements are observational units. Randomize treatment at the donor level, using interspersed blocks if spatial or temporal position could matter. If treatment must be applied within a donor, use a within-donor design for a different question and do not describe it as donor-level treatment replication. Blind the person scoring cells or images to treatment and the person analysing the primary contrast to donor identity where possible. Prespecify the allocation table and analysis plan.

Handling and analysis sequence. First summarize each donor, for example as a pseudobulk or donor-level summary, and fit the primary treatment contrast at the donor level. In parallel, fit a hierarchical or mixed model that includes the donor-level treatment effect and a donor-level random effect for repeated cells or fields. For confidence intervals, resample donors rather than cells. For a null distribution, use a null-imposed simulation or exchangeable treatment-label permutation respecting allocation blocks; an ordinary bootstrap is not automatically a null sample. Report both the number of observed cells or fields and the number of randomized units. Then perform held-out validation by splitting donors, not cells, into discovery and validation sets. The analysis sequence is: first verify allocation; second summarize at donor level; third fit donor-level and hierarchical models; fourth run grouped null calibration; fifth report uncertainty at both levels; sixth test position and time confounding; seventh validate on held-out donors.

Controls. Include vehicle or mock treatment, a null calibration in which treatment labels are permuted at the donor level, and a simulation in which the true effect is known. If possible, include a positive-control perturbation at the donor level and a negative-control perturbation. Map position and time for every observational unit. If cells within a donor are split across conditions, include a within-donor control analysis, but label it as within-donor, not donor-level treatment replication.

The primary quantitative contrast is the treatment effect estimated at the donor or animal level, with donors as the independent units. Report the point estimate, interval and the number of independent units. The secondary contrast is the same effect in a hierarchical model; differences may reflect weighting, estimands, link functions or imbalance; investigate them rather than diagnosing dependence from disagreement alone. A third contrast tests whether position or time is confounded with treatment.

Null calibration. Generate a null distribution by permuting treatment at the donor level, or by a parametric simulation that preserves the donor structure and variance components. Use this null to calibrate false-positive rates for the primary contrast. Do not use cell-level permutation, which would assume independence and nullify the correction. If the donor-level null is unstable because there are very few donors, report that the test has low resolution rather than claiming a definitive result.

Held-out validation. Split donors into discovery and validation sets before analysis. Fit the model on discovery donors and evaluate the prespecified contrast on held-out donors. Do not split cells from the same donor across discovery and validation, because that leaks donor-level information. If the number of donors is too small for a split, use prespecified cross-validation at the donor level or state that held-out validation is not feasible.

Sample-size and power planning. Power depends on the number of independent donors or animals, not the number of cells. Estimate variance components from a pilot; if unavailable, specify a calibration pilot and a minimum detectable donor-level effect. Because small independent n affects precision and robustness, report the uncertainty and avoid overinterpreting a significant cell-level test.

Prespecified exclusions and stopping rules. Exclude whole donors only by prespecified health, allocation or QC criteria; exclude cells or fields only by prespecified imaging or measurement quality rules that are applied blinded to treatment. Do not exclude cells because they change the donor-level contrast. Stop or downgrade the claim if treatment is perfectly aligned with position or time, if allocation is unrecoverable, or if the number of independent donors is too small to support the prespecified model.

Missing data. Distinguish missing donors from missing cells within a donor. If a whole donor is missing, do not replace it with cells from another donor. If cells are missing within a donor, prespecify a donor-level summary that is robust to unequal cell numbers, or use a hierarchical model with a missingness assumption. Report all missingness.

Expected results. A robust positive result would show a donor-level treatment effect with a grouped-null-calibrated interval that excludes no effect, with similar direction in held-out donors and no position or time confounding. An unsupported donor-level contrast despite a significant cell-level test may reflect underestimated uncertainty; it does not prove the biological effect is absent. An ambiguous result would show a point estimate similar under cell-level and donor-level models but much wider donor-level uncertainty, or a significant cell-level result that does not survive grouped resampling. Clustering may change uncertainty without changing the point estimate; that is still a valid outcome.

Artifact discrimination. Grouped resampling and hierarchical modelling address dependence. Pseudobulk summaries address cell-level weighting. Position and time mapping addresses spatial or temporal confounding. Interspersed blocked randomization addresses alignment. Donor-level held-out validation addresses overfitting. High intraclass correlation or loss of significance alone does not prove that a biological effect is absent; it changes the unit of inference.

Troubleshooting. If cell-level and donor-level models disagree, report both and do not choose the more significant one. If donor numbers are too small, increase independent donors rather than cells. If position is confounded, use blocked randomization and repeat. If the hierarchical model does not converge, simplify the random-effects structure and report the limitation. If the null calibration is unstable, use simulation with conservative assumptions.

Conditional conclusion. Only if the treatment effect is estimated at the randomized donor or animal level, with grouped null calibration, appropriate hierarchical or pseudobulk comparison, and held-out donor-level validation, should the data support a donor-level treatment conclusion. If the analysis relies on cells as independent treatment replicates, the result is pseudoreplicated for that claim. A non-significant donor-level test with very few donors supports uncertainty, not proof of no effect.

Curator clarification and operational extension. Define the estimand before aggregation: an equally weighted donor-average effect differs from a cell-weighted average when donor cell counts vary. Specify the outcome family and link function. A donor-summary regression on treatment is identifiable with independent donors; a cell-level model containing a separate fixed indicator for every donor cannot estimate a donor-constant treatment term. Use an appropriate random-intercept model only with justified distributional assumptions and enough independent clusters, and inspect convergence and boundary variance estimates. Permute treatment only within exchangeable allocation blocks; preserve pairing where relevant. Enumerate possible assignments when there are few donors and report the attainable p-value resolution. Estimate false-positive calibration across many null-generated datasets, rather than interpreting one permuted dataset as a measured false-positive rate. Simulation assumptions and parameter uncertainty must be explicit. Keep preprocessing, feature selection and thresholds inside each training fold. Cross-validation of prediction is distinct from confirmatory treatment-effect testing; lack of an independent holdout need not invalidate a prespecified correctly calibrated inferential analysis, but it limits external validation. Report the original and cluster-aware estimate with uncertainty and explain why a wider interval is not proof that the original biological claim is false.
