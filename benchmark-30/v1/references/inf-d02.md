# inf-d02: first-round reference

This is the unchanged first-round reference text. The owner confirmed careful review on 3 October 2026. Earlier pending-review statements inside the historical text are retained as part of the snapshot, not current metadata. Corrections and expanded execution requirements appear in version two.

All analyses below are proposed; no count matrix, sample sheet, reference or result file is available, so no execution is claimed. The plan is a reproducibility and differential-expression design for a bulk RNA-seq study whose inferential unit must be the independent treatment-allocation unit, documenting whether assignment was randomized, not a well or library merely because it has a distinct count profile.

Preparation and immutable inputs. Move all raw sequencing files, sample sheets, reference files, annotation files and code into a read-only project tree before analysis. Record checksums for every file and a manifest that links each checksum to its source and retrieval date. Keep the raw files immutable; all derived files are written to a separate output tree. If files are not supplied, create placeholders that must later be filled with the exact paths, versions and checksums; do not invent them. Preserve the original sample sheet as an immutable object and derive a working sample sheet from it by a scripted transformation.

Sample sheet and experimental-unit QC. The sample sheet must contain, at minimum, a unique sample identifier, raw-file path, condition, independent experimental unit, donor or animal identifier if applicable, processing batch, library batch, sequencing run, and any covariate used in the model. Verify that treatment is assigned at the level of independent allocation. If treatment was assigned to donors but multiple wells or libraries come from each donor, the donor is the treatment unit and wells are subsamples; do not fit a treatment contrast that treats wells as independent treatment replicates. If the design has only one donor, state that across-donor heterogeneity cannot be identified by adding a donor random effect. If the randomization history cannot be recovered, stop the inferential analysis and report the limitation.

Reference and annotation versions. Record the exact genome, transcriptome, annotation and software versions used for alignment and quantification. If the pipeline is alignment-based or alignment-free, record every tool, version, command and parameter. Freeze the reference and annotation before quantification. Run at least one alternative defensible annotation or quantification strategy as a sensitivity analysis, and report whether the primary contrast changes. Do not claim that one strategy is correct by default.

Count model and diagnostics. Fit a count model appropriate to the design, using a negative-binomial generalized linear model with information sharing for dispersion and effect estimation where justified. If the source method is used, record its version and all settings. Check the sample sheet against the count matrix, verify library sizes and count distributions, inspect dispersion estimates, and examine diagnostics for overdispersion, outliers and batch effects. If the design has repeated measures or donors, model the dependence structure at the correct level; standard DESeq2 supports fixed effects, not a generic random-effects formula; a donor random effect does not create donor replication. If the design is simple and independent, do not add unnecessary hierarchy.

The primary contrast is the prespecified treatment effect at the independent experimental-unit level. Define one primary contrast before looking at results. Specify the contrast coefficients, the model formula, the reference level, and the multiple-testing procedure, such as false-discovery-rate control, in the analysis plan. Report effect sizes with uncertainty and the number of independent units. Secondary contrasts are allowed only if prespecified or clearly labelled exploratory.

Plot regeneration and source-difference audit. Every figure and table must be regenerable from immutable inputs by a single documented command. Store the code, session information, package versions and random seeds. Regenerate all plots into a fresh directory and compare checksums or visual summaries with the original. For any difference, audit the source: raw file, sample sheet, annotation, quantification, model formula, contrast, filtering rule, or plotting code. Report the difference and its effect on the primary contrast. Do not overwrite the original outputs.

Controls and calibration. Include positive and negative control samples if the study design provides them; if not, state that they are absent. Calibrate filtering and independent-filtering choices in a prespecified sensitivity analysis, not by optimizing the result. If no pilot dispersion or effect-size estimate is available, specify a calibration pilot and required inputs rather than inventing variance or power numbers.

Sample-size and power planning. Power must be based on independent treatment units. Use a pilot estimate of dispersion and effect size if available; otherwise prespecify a calibration pilot. For donor-based designs, power depends on the number of donors, not the number of cells or libraries. Report the minimum detectable effect under the design and the uncertainty in the variance estimate.

Prespecified exclusions and stopping rules. Exclude samples only by prespecified QC rules, such as failed sequencing, sample-sheet mismatch, or failed library preparation. Do not exclude samples because they change the contrast. Stop the inferential analysis if treatment allocation cannot be verified, if independent replication is absent, if the sample sheet is ambiguous, or if processing is completely confounded with condition and no overlap exists. If batch is partly confounded, report the limitation and do not overstate adjustment.

Missing data. Distinguish missing raw files, missing sample-sheet fields, missing counts and missing covariates. Report each. Do not impute a treatment assignment or a donor identifier. If a covariate is missing for some samples, prespecify a sensitivity analysis rather than silently dropping samples.

Expected results. A reproducible positive result would show the same prespecified contrast and direction across reruns, with a stable FDR-controlled set and sensitivity analyses that do not reverse the conclusion. An inconclusive result may have an interval spanning zero; absence of a biologically meaningful effect requires adequate precision or a prespecified equivalence analysis. An ambiguous result would show a contrast that depends on annotation, quantification or batch handling, or a contrast driven by wells while donor-level replication is absent.

Artifact discrimination. The source-difference audit distinguishes true data differences from code or version differences. The sample-sheet audit distinguishes treatment-unit errors from biological effects. Alternative quantification tests address processing or quantification artefacts. Batch-overlap checks address confounding.

Troubleshooting. If counts do not match the sample sheet, stop and reconcile identifiers. If dispersion estimates are unstable, inspect the design and consider a model appropriate to the unit structure. If batch and condition are confounded, do not claim an adjusted effect. If plots differ, reproduce the difference from raw inputs and document the cause.

Conditional conclusion. Only if the treatment contrast is estimated at the correct independent unit, with immutable inputs, recorded versions, prespecified contrast and FDR, regenerated plots, and a source-difference audit that explains any discrepancies, should the analysis support a reproducible differential-expression conclusion. If independent replication is missing or allocation cannot be recovered, the model output cannot create it.

Curator clarification and operational extension. Before computation, identify the publication, raw-data accession and exact target panels; their absence blocks a claim of paper reproduction. The assessment here is a plan, not a measured pipeline pass. When inputs arrive, verify checksums, read pairing and strandedness; summarize adapter content, quality profiles, alignment/assignment fractions, sample identity, contamination and library complexity. Archive the exact reference release and gene identifier mapping. Feed appropriate raw gene counts to DESeq2, not TPM or already log-normalized expression; for transcript quantification use a documented compatible import that preserves required offsets. Prespecify filtering, size-factor estimation, dispersion fitting, contrast sign, multiple-testing family and FDR threshold. For fully crossed paired samples, a full-rank design such as donor plus condition can account for donor fixed effects. If condition is constant within donor, saturated donor indicators absorb condition; choose an identifiable donor-level design or a suitable hierarchical method instead. Check model rank before fitting. Distinguish inferential tests from effect-size shrinkage and ensure the shrinkage estimator supports the chosen coefficient or contrast. Regenerate PCA from an appropriate transformed matrix, MA and volcano plots from the exact results table, and target gene panels with explicit normalization. Compare numeric data behind plots, not image hashes alone; rendering metadata can change a byte hash while results agree. More reads or wells cannot replace independent biological replication. Ordinary observational designs can still estimate associations when allocation is documented, but randomized causal interpretations require randomization or defensible identification assumptions.
