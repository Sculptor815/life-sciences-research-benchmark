# Ten-paper integrity-audit selection

Ten original papers are selected across nine source families. All have official retraction records, but the evidentiary grounds differ. This is a selected teaching set, not an estimate of misconduct prevalence. The two STAP papers must remain in the same split. The private collection contains ten original essay questions with 502–539-word reference answers; packets are paraphrased drafts pending source, rights and expert audit, not completed raw forensics.

## Evidence and scoring

Each essay traces a localized observation to a measurement failure, the affected comparison, and the justified limit on a biological claim. It must consider benign alternatives and identify evidence that could overturn the concern. Apply the essay concept/logic rubric in METHOD.md; keywords without correct relations earn no logic credit. The ten selected cases need matched reliable and corrected-but-valid controls before a detector benchmark can measure false accusations.

SNU's [official investigation](https://en.snu.ac.kr/snunow/snu_media/news?bbsidx=71497&md=v) supports the Hwang fabrication classification. [ORI's case report](https://ori.hhs.gov/images/ddblock/march_vol23_no1.pdf) names the Potti paper; do not transfer numerical alterations described for other papers onto this one. Non-replication in NgAgo, chemical contamination concerns in GFAJ-1 and analysis artifacts in the cancer-microbiome paper are not themselves proof of fabrication or intent.

Use a technical-evidence stage before disclosing notices, then score calibrated revision separately. The current drafts retain public source locators and cannot be called blinded or resistant to memorization. Original raw files and figure-level forensic outputs have not been independently reproduced for all ten.

For the cancer-microbiome case, include both the [primary reanalysis](https://pmc.ncbi.nlm.nih.gov/articles/PMC10653788/) and the [author response](https://www.nature.com/articles/s41388-024-02974-w). A reproducible computational artifact is still an artifact; replicating a plot does not validate its biological interpretation.

## Prior work worth testing

- [HMS-IDAC ImageForensics](https://github.com/HMS-IDAC/ImageForensics): Transformation-tolerant scientific image similarity; candidate matches require independent panel/metadata review. Repository description and provenance read; code not executed, weights and license not yet audited.
- [SILA-derived Copy-Move Detection Module](https://github.com/researchintegrity/copy-move-detection): Within-image and between-image region matching, with visualized candidate correspondences. README read; code not executed. README notes a non-commercial restriction in an underlying component; perform a license audit before redistribution.
- [statcheck](https://github.com/MicheleNuijten/statcheck): Recompute reported significance tests from statistic and degrees of freedom; follow every flag with manual examination of rounding, sidedness, corrections and extraction quality. Official project/release and documentation descriptions read; not installed. Does not establish fabricated data.
- [Cancer Microbiome Reanalyzed](https://github.com/yge15/Cancer_Microbiome_Reanalyzed): Primary reanalysis supplementary tables and database identifiers for a concrete bioinformatics audit. README and listed artifacts read; repository/data not downloaded or executed.
- [Author cancer-microbiome response](https://github.com/gregpoore/tcga_rebuttal): Counteranalysis and reported code for specific methodological disputes; include alongside the critique. README read; scripts not executed.
- [Baggerly and Coombes forensic bioinformatics materials](https://bioinformatics.mdanderson.org/Supplements/ReproRsch-All/Modified/StarterSet/index.html): Original investigators' reproducibility and data-provenance case materials; use exact paper-to-file mapping. Resource index and primary reanalysis abstract read; not a GitHub repository and not executed.

Freeze tool versions, licenses, thresholds and test data before use. Tool alerts require review: image similarity, statistical inconsistency or a missing record alone cannot identify motive.
