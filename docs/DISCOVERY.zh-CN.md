# 从原始发现到候选评测题

私有目录中的 `research/REVIEW.html` 是本轮选题入口，双击即可在浏览器中审阅。它包含论文来源、阅读深度、原始问题、实验设计、推断边界、伪影假说、候选题、参考答案和评分要点。所有案例均待人工审核，页面不上传意见。这个页面含答案，不应发给被评测模型。

## 教材筛选与追溯

核心教材应有美国顶尖大学正式课程实际采用的证据。记录课程名称、学校、学期、版次、必读或推荐、学校官方链接。历史大纲只能证明当年采用；不能据此声称最新版本正在被该校使用。课程采用是质量筛选依据之一，仍需按领域覆盖、原始证据和教学清晰度人工判断。

优先书目包括分子领域的 Alberts、Lodish，生化领域的 Stryer/Berg、Voet 等，神经领域的 Kandel、Purves、Bear，以及生信领域的 Durbin、Jones/Pevzner 等；最终采用记录以私有 `textbook-adoption-*.json` 为准。Pevsner 的出版社章节参考文献已经单独检索，但课程中引用它与指定它作为教材是不同证据。OpenStax、LibreTexts 仅作为补充，不计核心教材覆盖。

每条知识链分为五步：课程教材采用 → 具体版次/章节 → 该章节实际参考文献 → 原始研究/后续验证 → 题目证据包。主题相似不等于书中实际引用。完整读取一个章节的参考文献页，也不等于穷尽支撑知识的全部文献。缺失层级必须保留，不用模型猜测补齐。

当前80概念清单是检索计划；46案例/178候选题另行统计。已提取 MIT 课程指定的 Jones & Pevzner 2004 教材全部114条书目，并定位比对与HMM章节实际引用编号；这不等于114篇原论文全部读完。另有7个补充书目单元365条，不能把它们计作核心教材覆盖。大多数候选论文与核心教材之间的直接引文链接仍待逐条核定。完整主文阅读、部分段落阅读、摘要阅读、后来的作者回顾分别记录，不能相互替代。

## 怎样审核

1. 在页面筛选领域或搜索概念。检查论文来源及哪些正文/图表已读、哪些未取得。
2. 展开候选题与固定材料，再看参考答案。答案必须由给定材料或题目明确要求的基础知识支持；不应要求被测模型联网补材料。
3. 选择保留、修改或剔除，填写理由。“保留候选”需要确认来源、题目公平性、答案与使用权四项。
4. 导出审核 JSON。浏览器保存仅是方便继续编辑；导出文件才是可转交的记录。

本地审核者姓名是自述身份，不是账户认证。页面意见和导入记录不会自动将题目变成正式金标准。正式入库仍需独立双人审核、逐题0–4评分锚点、合理替代答案、盲评校准与来源家族隔离。

在公开项目目录中运行以下命令；所有输出使用新路径以保留历史版本：

```powershell
.\.venv\Scripts\lsrw.exe research audit --corpus '../life-sciences-research-workbench-private/research/corpus-v0.2.json'
.\.venv\Scripts\lsrw.exe research review --corpus '../life-sciences-research-workbench-private/research/corpus-v0.2.json' --output '../life-sciences-research-workbench-private/research/REVIEW-next.html'
.\.venv\Scripts\lsrw.exe research import-decisions --corpus '../life-sciences-research-workbench-private/research/corpus-v0.2.json' --decisions 'EXPORTED-REVIEW.json' --output '../life-sciences-research-workbench-private/candidate-reviews'
```

导入会核对整份资料与每个案例的哈希，拒绝旧版本、重复或缺少依据的决定。`research export` 将题干/固定材料和私有答案分别保存；导出仍是草稿，不能直接伪装成正式320题。

## 有争议的文献怎样出题

PubPeer 是发现线索的来源，评论数量、作者未回复、未能重复均不能单独证明造假。分别记录原始结论、具体质疑、作者回应、期刊公告、独立复核与当前未知。撤稿事实由官方公告核对，撤稿不自动否定领域中所有相关结论，也不能推出个人意图。

同时检验选择性报告：是否给出所有尝试的分母、预注册终点、排除规则、完整效应分布、阴性与失败结果。原图可以真实，展示子集仍可能误导；缺失数据并不自动意味着缺失结果为阴性。本轮有明确标为虚构的完整档案练习，不把虚构数值归给真实作者。

## 出题联网，答题固定材料

出题者可以检索出版社、PubMed、原论文、公告和课程大纲。被测模型只收到冻结后的题目、选项和材料，不收到参考答案、争议判词、评分细则或审核记录。Workbench 的问答接口只支持 `fixed_packet`，传入空工具列表，禁止工具调用，发现模型请求工具时记为运行错误。

这能检查客户端请求与响应，不能观察远端供应商的内部检索。需要更强的断网保证时，应另用可审计的本地推理/网络隔离环境。当前未执行 agent 生成代码的操作系统级断网评测；不能用一句提示词冒充隔离。

## 从已有发现提出新问题，再评价问题质量

私有资料另含12个研究方向，每域3个，附竞争假说、判别实验、可解释阴性结果、参考设计和逐维AI初评。它们是待筛选的研究提案；“新提案”不等于世界首次，作者进入教材也不等于其所有研究都有同等可信度。

公开的 `templates/question-quality-rubric.json` 提供六维0–4分锚点：重要性、证据依据、有界新颖性、可检验性、区分解释的能力、条件下的可行性。它是本项目的待验证评分方案。高质量问题可以得出有价值的阴性结果；参考设计只是可接受答案之一。初轮隐藏作者、机构、模型来源和已有得分，由两位评分者独立评判，避免名望或答案长度带来的偏差。

现实新颖性由作者/审核团队记录当前文献检视，被评测模型仍只能看冻结材料。未完成检视时，新颖性和总分为 `null`，其他五维可显示描述分 `/20`，不能据此发布排名。即使六维齐全，工具也只检查评分记录与求和，不自动批准科学结论。

```powershell
.\.venv\Scripts\lsrw.exe question-quality --record 'PRIVATE-QUESTION-RATING.json' --output 'NEW-QUALITY-SUMMARY.json'
```

按模板填写每个分值及理由。问题本身的质量和agent任务表现分别报告；不能用单个好问题的分数宣称模型总体能力。冻结包未提供的后续先例，应影响现实新颖性说明，而不能当作模型编造事实来处罚。

## 分析流程实际跑了什么

`scripts/check_analysis_pipelines.py` 在固定随机种子的合成数据上执行七项检查：富集ORA、双视图CCA、供体聚合与探索性差异分析、协变量调整的定量性状关联、Scanpy单细胞分析、扩散拟时序、VCF下游质量过滤。报告记录软件版本、输出哈希、验收条件和限制；单细胞测试实际剔除一个低质量细胞并检查标签对齐。

可在安装 `.[analysis]` 的独立科学环境运行：

```powershell
python -X utf8 scripts/check_analysis_pipelines.py --output 'NEW-PRIVATE-OUTPUT-DIRECTORY'
```

本轮使用机器上已有的科学环境，路径和版本已记录在私有 `pipeline-checks/2026-10-03-v2/pipeline-report.json`。它们不是完整的 GATK、DESeq2、MOFA，也不是实际队列或agent自主生成程序的验证。完整WGS、真实数据外部验证、批次/相关结构更复杂的GWAS与隔离代码执行仍是独立待办。退出成功仅表示已实现的七项检查通过。
